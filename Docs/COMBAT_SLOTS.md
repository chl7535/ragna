# 전투 슬롯 규칙

내 턴에는 준비한 공격을 왼쪽부터 전부 실행하고, 이후 적 한 마리가 한 번 공격한다.
평타 / 평타 / 스킬 구성은 내 턴에 평타 두 번과 스킬 한 번을 실행한다.
3칸 스킬은 준비 공간만 3칸 차지하며 한 턴에 한 번 발동한다. 충전 턴은 없다.
각 공격 슬롯은 가장 가까운 살아 있는 적 한 마리만 타깃으로 잡는다. 연타 스킬도 같은 적만 공격하며,
도중에 죽으면 남은 타격은 종료한다. 다음 슬롯이 실행될 때 뒤의 살아 있는 적을 새로 선택한다.
이 규칙은 모든 직업에 공통 적용하며, 넓은 스킬 이펙트가 표시되어도 다른 적에게 피해를 주지 않는다.

슬롯 수 = 기본 1 + 첫 전직 완료 시 1 + 누적 전승(기존 환생) 횟수.
처음 1칸, LV.20 전직 후 2칸, 1회 전승 후 새 모험가 2칸, 다시 전직하면 3칸이다.
4회 전승하고 첫 전직을 마치면 6칸이다. LV.60·100에는 슬롯을 추가하지 않는다.
패시브는 기존처럼 각 5단계까지이며, 최대 단계에서도 전승하여 영구 슬롯을 얻을 수 있다.

## 준비와 저장

시작·전직 후 준비창에서 셀을 선택하고 공격을 배치한다. 빈 공간은 평타로 채운다.
여러 칸을 차지하는 스킬의 어느 셀을 교체해도 이전 스킬의 전체 예약을 해제한다.
필요한 연속 공간이 부족하거나 스킬 레벨이 낮으면 배치할 수 없다.
전투 중 하단 준비 버튼은 현재 턴을 멈춘다. 진행 중 콤보는 유지하고 변경 구성은 다음 내 턴에 적용한다.
설정을 완료해야 전투가 재개된다. 물약과 보호막은 기존처럼 직접 사용한다.
저장 버전5는 구성·현재 턴·콤보 위치를 보존한다. 버전1~4 전투는 준비 상태로 복원한다.

## 데이터 확장

Assets/Ragna/Resources/CombatActions 아래 CombatActionDefinition 자산을 추가한다.
고유 id, 표시명, basicAttack, slotCost, minSkillLevel, effectTier, damageMultiplier, bonusHits로 설정한다.
현재 기본 데이터는 평타 1칸, 스킬 1/2/3/6칸이며 필요 스킬 레벨은 각각 1/4/8/12다.
이 수치와 명칭은 초기 밸런스 값이다. 스킬의 기본 연출은 직업과 성장 단계에 따른다.
ragna_combat_setup 명령은 없는 기본 자산만 생성하며 기존 편집값은 덮어쓰지 않는다.
새 슬롯 획득 조건은 추후 사용자 결정 후 SlotCapacity에 추가한다.
