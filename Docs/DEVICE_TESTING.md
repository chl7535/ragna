# 스마트폰 테스트 — Ragna 0.1.0

## Android

설치 파일: `Ragna/Builds/Android/Ragna.apk`.
Android 8.0(API 26) 이상, ARM64 기기용이다. 세로 화면에서 좌→우 횡스크롤로 전투한다.
테스트용 Android Debug 인증서로 서명했다. 배포용 서명 키와는 다르다.

APK를 휴대폰에 복사한 뒤 파일을 열어 설치한다. 해당 파일 앱의 외부 APK 설치 허용이 필요할 수 있다.
같은 앱 ID를 다른 인증서로 설치한 이력이 있으면 업데이트가 거절될 수 있다.
이때 앱 삭제는 로컬 저장을 지우므로 기존 기록을 먼저 확인한다.

USB 디버깅이 허용된 기기에서는 Unity Android SDK의 `adb install -r`에 APK 경로를 지정할 수 있다.
`Tools/Verify-Android.ps1`은 기기 설치 없이 APK 서명·앱 ID·ARM64 IL2CPP·최소 API·세로 방향을 검사한다.
결과는 `Docs/APK_VERIFICATION.json`에 있다. 이는 실제 기기 플레이 검사를 대체하지 않는다.

## 기기에서 확인할 흐름

1. 실행 → 직업 선택 → 튜토리얼 → 전투. 오른쪽 적과 공격 효과가 화면 안에 보이는지 확인한다.
2. HP 감소 후 물약, 공격 예고에 보호막을 사용한다. 터치 영역과 재사용 대기 표시를 확인한다.
3. 층 완료 강화 선택, 검사 20레벨의 기사·광전사 선택, 60·100레벨 승급을 진행한다.
4. 스킬 레벨 4·8·12에서 효과가 커지는지, 환생 후 패시브를 계승하는지 확인한다.
5. 홈 화면 이동·앱 복귀·앱 종료 후 재실행 시 일시정지와 저장 복원을 확인한다.
6. 노치·긴 화면에서 HP와 물약 버튼이 가려지지 않는지, 연속 플레이 중 발열·프레임 저하를 확인한다.

문제 기록에는 기기명, OS 버전, 직업·전직, 층·레벨, 재현 순서와 화면을 포함한다.

## iPhone

Windows에서는 Xcode 프로젝트 내보내기까지 진행한다. 서명·iPhone 설치는 Mac의 Xcode에서 한다.
내보내기가 성공하면 `Ragna/Builds/iOS/Unity-iPhone.xcodeproj`를 Mac에서 열고
실제 Apple 개발 팀과 앱 ID로 Signing 설정을 완료한 뒤 연결된 iPhone을 대상으로 빌드한다.
Mac에서는 해당 Unity 버전 및 Xcode와 호환되는 iOS SDK를 사용한다.
