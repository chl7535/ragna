# 사용자 제공 배경 적용

첨부받은 서로 다른 원본 6개를 수정 없이 Unity에 복사했다. 반복 첨부된 화산·숲·폐성·마성·해안은 중복 사용하지 않는다.
파일 위치: `Ragna/Assets/Ragna/Resources/Backgrounds/`.

| 층 | 파일 | 지역 |
|---|---|---|
| 1–5 | 01-meadow.png | 시작의 초원 |
| 6–10 | 02-forest.png | 고대의 숲 |
| 11–15 | 03-coast.png | 푸른 해안 |
| 16–20 | 04-ruins.png | 잊힌 폐성 |
| 21–25 | 05-volcano.png | 불타는 화산 |
| 26–30 | 06-citadel.png | 월식의 마성 |

원본 비율을 유지하고 세로 전투 영역을 채우도록 좌우를 잘라 표시한다. 길의 높이는 그림별 비율로 맞춘다.
한 장으로 완성된 배경이므로 이미지 내에서 천천히 왼쪽으로 이동하고 끝에 도달하면 멈춘다.
이어지지 않는 양끝을 붙이거나 원본을 좌우 반전하지 않는다. 레이어가 분리된 패럴랙스는 아직 아니다.
기존 프로그램 생성 달·폐허·바닥은 제거했다. 캐릭터와 공격 이펙트는 배경보다 앞에 표시한다.

배경은 Bilinear, 원본 캐릭터·도트는 Point를 유지한다. 배경 mipmap과 CPU 읽기는 끄고 모바일 ASTC 6×6을 설정했다.
가져오기 재현: `Tools/Import-Backgrounds.cs`를 Unity CLI eval로 실행한다.
원본 PNG를 재생성하거나 편집하지 않았으므로 이미지 생성 도구는 사용하지 않았다.

`BACKGROUND_CHECKS.txt`: 42개 검사 통과. 6개 지역 경계, 3개 세로 화면 비율의 화면 채움, 실제 카메라 렌더 확인.
`BackgroundGallery/index.html`에서 6개 적용 화면을 비교할 수 있다.
현재 APK/iOS 출력은 이 변경 전 빌드다. 최신 원화·애니메이션·배경을 포함해 다시 빌드한 후 기기를 검증한다.
