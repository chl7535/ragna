# 전직 추가 방법

시작은 **모험가**이며 20레벨에 일곱 기본 직업 중 하나를 선택합니다. 현재 검사의 60레벨 분기는 **기사 / 광전사**입니다.
60레벨은 2차 전직, 100레벨은 선택한 길의 3차 승급입니다. 추가 분기 이름은 사용자와 함께 정합니다.

## 현재 데이터

| ID | 이름 | 전직 효과 | 외형 |
|---|---|---|---|
| knight | 기사 | HP +15%, 받는 피해 12% 감소, 보호막 지속 +0.4초 | 검과 방패, 푸른 오라 |
| berserker | 광전사 | 공격력 +20%, 공격 속도 +15% | 큰 양손검, 붉은 오라 |

두 자산은 `Assets/Ragna/Resources/Careers/`에 있습니다.
계승 패시브는 현재 기본 직업 기준입니다. 기사/광전사 모두 검사 패시브인 더블 어택을 계승합니다.

## 새 분기 만들기

1. Unity Project 창에서 `Create > Ragna > Career`로 자산을 만듭니다.
2. `Assets/Ragna/Resources/Careers/` 아래에 저장합니다.
3. `id`에는 고유하고 변하지 않는 식별자를 입력합니다. 출시 후 ID를 바꾸면 기존 저장의 연결이 끊깁니다.
4. `baseJob`과 `promotionStage`(2/3), `unlockLevel`(60/100)을 지정합니다.
5. `requiredCareerId`는 앞 단계 전직 ID입니다. 비우면 해당 기본 직업의 모든 이전 전직에서 선택할 수 있습니다.
6. 이름·설명과 공격력/HP/속도/받는 피해 배율, 보호막 추가 지속시간, 색상을 지정합니다.
7. `appearance`는 가제작 외형입니다. 0=기본, 1=방패, 2=양손검.
   최종 도트가 있으면 `promotionSprites`의 0~3 인덱스에 승급 단계별 Sprite를 넣습니다.
8. 새 한국어 이름을 입력했다면 `Ragna > Refresh Korean font`를 실행합니다. 모바일 빌드 시에도 자동 반영됩니다.
9. Play를 다시 시작하면 자동으로 목록에 나타납니다. ID 중복은 오류로 알려줍니다.

예: 기사에서 갈라지는 100레벨 직업은 `baseJob=Warrior`, `promotionStage=3`,
`unlockLevel=100`, `requiredCareerId=knight`로 만듭니다.
새 단계 데이터의 능력 배율은 이전 전직 데이터에 곱해 누적되는 값이 아니라 **현재 전직의 최종 배율**입니다.
전직 자산이 없는 단계에서는 기존 길을 유지한 채 승급합니다.

이 구조에서 새 분기와 능력 보정·기본 외형은 전투 C# 수정 없이 추가할 수 있습니다.
새로운 고유 전투 동작이나 완전히 다른 무기는 별도 구현이 필요합니다.

## 검증

전직을 추가한 뒤 `Ragna > Run model checks`와 실제 Play 화면을 확인하세요.
현재 자동 플레이 검사는 승인된 기사 루트와 광전사 루트를 포함합니다.
기본 자산 생성 도구 `ragna_careers`는 기존 능력치를 유지하며, 기존 기사·광전사 20레벨/1단계 설정만 60레벨/2단계로 변환합니다.
