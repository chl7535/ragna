# 자동사냥과 바닥 이동

2026-10-29 변경: 턴 교대는 폐기했다. 캐릭터는 살아 있는 가까운 몬스터를 찾아 좌우와 바닥 위아래로 자동 접근한다.
높이는 바닥의 깊이 좌표이며 공중 높이가 아니다. 점프·중력·점프 입력은 없다.

## Unity에서 조절하기

Assets/Ragna/Resources/HuntingMap.asset을 선택하면 Inspector에서 다음을 수정할 수 있다.
- Horizontal Bounds: 좌우 이동 경계
- Depth Bounds: 바닥 위아래 이동 경계
- Hero Speed / Enemy Speed: 자동 추적 속도
- Sword Reach: 공격 가능한 좌우 거리
- Depth Tolerance: 공격 가능한 위아래 거리
- Enemy Attack Interval: 적마다 독립적인 공격 주기

기본 이동 범위 X -4.8~4.8 / Y -3.6~-1.8, 검사 사거리1.5 / 깊이 허용0.28.
현재 검사를 먼저 확인하는 공통 이동 설정이다. 다른 직업의 원거리 특화·별도 사거리 설계는 이후 작업이다.
현재 배경 원화는 한 장이라 실제 지형·장애물 경로 탐색은 없다. 이동 경계 안의 열린 평면이다.

## 전투

공격 슬롯은 기존대로 편집하며, 자동사냥 중 순서대로 반복 실행한다.
캐릭터는 사거리 밖에서는 이동하고, 좌우 거리와 위아래 폭이 모두 맞아야 공격한다.
다음 슬롯까지 공격 속도에 따른 간격을 둔다. 적은 플레이어 공격 순서를 기다리지 않는다.
각 적은 자기 공격 타이머와 범위 판정으로 공격하며, 동시에 여러 적에게 맞을 수 있다.
한 슬롯의 연타는 한 몬스터에게 고정하고, 처치 시 남은 타격을 종료한다. 다음 슬롯에서 새 타깃을 찾는다.
물약과 보호막은 수동 사용한다. 준비창·강화·전직·일시정지 중에는 이동과 공격을 멈춘다.
캐릭터와 적의 그림자는 바닥 위치를 따르며, 화면 아래쪽의 몸체가 위쪽 몸체보다 앞에 그려진다.

## 저장과 검증

저장 버전6은 캐릭터 바닥 X/Y·방향·공격 순서·적의 독립 공격 타이머를 유지한다.
이전 저장은 진행과 슬롯을 보존하고 바닥 좌표로 변환한다.
ragna_hunting_checks는 추적·사거리·깊이·경계·독립 공격·타깃·저장 검사를 실행한다.
이전 TURN_CHECKS.txt는 턴제 시절 기록이며 현재 자동사냥의 검사 결과가 아니다.
최신 모바일 빌드와 실제 기기 검증은 아직 하지 않았다.

검증 완료: 자동사냥20 / 게임 규칙71 / 전체 UI31 / 준비창13. 실제 접근·전투 화면은 Screenshots/auto-hunting-depth.png, auto-hunting-contact.png.
보스 체력4배·최대HP 비례 피해24%·적 주기1.6초·첫 공격0.6~0.8초는 현재 데이터의 초기 밸런스다. Inspector에서 조절 가능하다.
