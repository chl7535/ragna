# Ragna 0.1.0 — 개발 상태

2026-10-23, Unity 6000.3.26f1 LTS / URP 2D / 세로 모바일·횡스크롤 전투 / 광고·결제 없음.

## 모험가 시작 전직 구조 (10월 23일)

모든 새 도전·환생 후 도전은 LV.1 모험가로 시작한다. LV.20에 검사·궁수·법사·거너·격투가·성직자·도적 중 선택한다.
기사·광전사는 검사 LV.60의 2차 전직으로 이동했다. LV.100 3차 승급과 해당 직업 패시브 계승은 유지한다.
모험가 단계에도 기존에 계승한 패시브가 적용된다. 첫 전직 시 HP 회복·직업 스킬 전환·스킬 +2·물약 +2.
저장 버전 4: 이전 20레벨 미만은 레벨·메타를 유지한 모험가로 전환하고, 20레벨 이상은 기존 직업·전직을 보존한다.
새 시작·일곱 직업 선택·승급·환생·저장 복원 검사 68개 및 UI 검사 24개 통과. 기존 20레벨 전직 대기 상태가 막히지 않는지도 확인했다.
Screenshots/adventurer-camp.png와 first-job-choice.png는 저장과 분리한 실제 에디터 검증 화면이다.
현재 APK/iOS 출력은 이번 전직 구조까지 포함하지 않은 이전 빌드다.

## 배경 6종 적용

사용자 제공 초원·숲·해안·폐성·화산·마성 원본을 보존해 5층 단위 지역에 연결했다. 반복 첨부는 제외했다.
세로 화면의 길 높이와 화면 채움을 보정하고 이미지 내부에서 패닝한다. 배경은 한 장이며 아직 패럴랙스 레이어는 아니다.
배경 검사 42개와 전투46/UI20 검사 통과. 실제 화면은 BackgroundGallery/와 Screenshots/background-meadow.png.
기존 모바일 빌드는 새 원화·애니메이션·배경 적용 이전 결과다. 최신 빌드 재생성 후 기기 검증 예정.

## 첨부 원화 적용

사용자 참조의 갈색 머리·초록 망토·가죽 장비 캐릭터를 28프레임으로 재제작해 검사에 적용했다.
실제 게임 화면은 Screenshots/reference-adventurer.png, 움직임은 SkillGallery/character-animations.gif.
다른 직업은 기존 도트를 유지한다. 검사 전직별 갑옷·무기 원화는 별도 제작이 필요하며 현재는 같은 복장에 성장 오라와 스킬 단계를 유지한다.

## 10월 20일 변경

애니메이션·스킬을 우선 개발하고 기기 검증은 이후로 진행한다.
기존 도트를 기반으로 대기·이동·공격·시전·피격·사망·보호막 프레임을 생성·캐시한다.
적도 이동·공격·피격·사망을 표현하며, 플레이어 사망 후 0.65초 동안 쓰러지는 연출을 보여준다.
일곱 직업의 스킬 형태·확산·연속 발사·강타·빛 기둥을 분리하고 각 4단계 성장 연출을 적용했다.
`VISUAL_CHECKS.txt` 196개 검사 통과(참조 원화 28프레임 포함). 28개 단계의 실제 카메라 렌더와 움직이는 프레임 미리보기는 `SkillGallery/`.
아트는 기존 프로그램 생성 도트 기반의 1차 애니메이션이며 최종 수작업 아트는 여전히 보강 대상이다.
기존 APK와 iOS 출력은 이 애니메이션 변경 이전 빌드다. 기기 검증 전에 최신 소스로 다시 빌드해야 한다.

사용자 선택에 따라 세로 화면을 유지하고 좌→우 횡스크롤 전투로 변경했다.
적의 가로 접근·근접 판정·자동 타깃, 오른쪽 공격·스킬, 가로 이동 배경을 적용했다.
저장 버전 3은 버전 1·2의 수직 좌표를 변환한다. 캐릭터 성장과 메타 진행은 유지한다.
`Screenshots/side-*.png`가 변경 후 실제 에디터 화면이며 이전 파일은 수직 구도 기록이다.

## 구현 및 확인

- 일곱 기본 직업과 서로 다른 자동 공격·스킬 성향.
- 자동 전투, 수동 물약(5초), 보호막(8초). 정확한 막기는 반격 스킬을 발동한다.
- 30층, 다섯 층마다 보스, 세 가지 중 하나를 선택하는 무작위 강화.
- 20·60·100레벨 승급과 스킬 4단계 시각적 진화.
- 모험가 20레벨 첫 직업 선택, 검사 60레벨 기사/광전사 선택. 부모 ID·승급 단계로 확장하는 전직 데이터.
- 환생으로 기본 직업 패시브 영구 계승, 직업별 최대 5단계.
- 사망·승리·재도전·환생·직업 재선택·음량·진동 설정.
- 원자적 로컬 저장과 백업 복원, 저장 버전 마이그레이션, 앱 이탈 시 일시정지.
- 원본 임시 도트와 합성 효과음, 한국어 정적 SDF 글꼴.
- 모바일 빌드에도 명시적으로 참조되는 URP 스프라이트 머티리얼.

## 검증 근거

`MODEL_CHECKS.txt`: 68개 검사 통과. 가로 이동·타깃·근접 판정·저장 좌표 변환·중복 변환 방지를 포함한다.
고정 시드 731로 일곱 기본 직업(검사는 기사 루트)의
능동 플레이는 모두 30층 정복, 물약/보호막 미사용 플레이는 모두 사망했다.
광전사 루트의 능동 플레이도 30층을 정복했다. 이는 모든 랜덤 빌드의 난이도 보장은 아니다.
현재 한 도전은 검증 봇 기준 약 5~6분으로, 장기 플레이 분량과 밸런스는 후속 조정 대상이다.

`UI_CHECKS.txt`: 실제 버튼 이벤트 기반 24개 검사 통과.
튜토리얼, 물약, 일시정지/계속하기, 기사 전직, 강화 선택, 환생, 사망 후 캠프 복귀를 확인했다.
이 검사는 물리 스마트폰의 터치·제스처·백그라운드 동작 테스트를 대체하지 않는다.

`Screenshots/`: 에디터의 실제 Game 화면. 성장 미리보기는 저장과 분리된 개발 전용 고정 상태이며,
정상 플레이로 획득한 기록처럼 저장하지 않는다.

## 빌드 상태

- 2026-10-20 횡스크롤 버전 Android APK 빌드 성공. `Ragna/Builds/Android/Ragna.apk`, 36,908,223바이트.
- `Tools/Verify-Android.ps1` 검사 통과: APK v2 서명, 앱 ID `com.ragnastudio.ragna`, ARM64 IL2CPP, Unity 네이티브 라이브러리, 최소 API 26, 세로 방향.
- Android Debug 인증서로 서명한 로컬 테스트 빌드다. 배포용 키는 아직 설정하지 않았다. 검증 기록은 `APK_VERIFICATION.json`.
- 연결된 Android 기기가 없어 실기기 설치·플레이는 검증하지 않았다. 절차는 `DEVICE_TESTING.md`.
- 원본 한글 경로는 Android 도구가 지원하지 않아 `Tools/Build-Mobile.ps1`이 영문 임시 폴더에 복사해 빌드한다. 이전 중단의 잠금 파일을 안전하게 처리하도록 보완했다.
- iOS Xcode 프로젝트 내보내기 성공: `Ragna/Builds/iOS/Unity-iPhone.xcodeproj`. IL2CPP 게임 소스·데이터·앱 ID·iOS 15 최소 버전·세로 방향 검사 통과. 기록은 `IOS_EXPORT_VERIFICATION.json`.
- iOS는 Xcode 컴파일·서명·기기 설치를 아직 하지 않았다. Mac/Xcode에서 이어서 진행한다.

## 출시 전에 필요한 작업

출시 완성본이 아닌, 요청한 핵심 루프를 검증하는 첫 플레이 버전이다.
최종 캐릭터·몬스터 애니메이션, 스킬 아트, 배경·음악·효과음 제작과 교체가 필요하다.
나머지 직업 분기와 60·100레벨 상세 루트는 사용자와 함께 정한다.
실기기 터치·화면 비율·노치·발열·메모리·장시간 저장 검증이 아직 필요하다.
iPhone 서명·설치는 macOS/Xcode와 Apple 개발자 설정에서 진행한다.
스토어 서명 키, 실제 앱 ID, 아이콘, 스토어 소개, 개인정보 관련 표시와 심사는 별도다.

새 전직 추가 방법은 `CAREER_AUTHORING.md`, 아트 규격은 `GAME_DESIGN.md`에 있다.
