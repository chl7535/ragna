# 남겨 둔 직업 확장 구조

현재 구현과 선택 가능한 직업은 모험가 → 검사 → 기사/광전사뿐이다.
삭제한 직업은 이름·스킬·전투 계산·전용 연출·무기 그림·계승 효과·미리보기 이미지에서 제거했다.

## 기존 저장

저장 버전7부터 다른 직업 ID는 유효하지 않다.
이전 저장의 삭제된 직업은 20레벨 미만이면 모험가, 20레벨 이상이면 검사로 바꾼다.
기존 2차/3차 승급은 기사 계열로 연결한다. 레벨·층·전승 횟수·최고 기록·슬롯 구성은 유지한다.
계승은 검사 더블 어택만 남기고 삭제한 직업의 패시브는 제거한다.
기존 모험가와 검사·기사·광전사 저장은 해당 루트를 유지한다.
실제 사용자 저장을 검사 도중 덮어쓰지 않았다. 다음 정상 저장부터 새 형식으로 기록된다.

## 향후 추가할 때

전직 공통 코드와 CareerDefinition, CombatStats, CombatActionDefinition 자산 구조를 유지했다.
새 직업을 추가할 때는 새 Job enum ID와 JobData 표시 데이터/AvailableJobs에 등록한다.
기존 ID0(검사),7(모험가)은 변경하지 않는다. 삭제된 ID1~6은 구버전 변환용 예약값이며 재사용하지 않는다.
AvailableJobs의 기존 순서를 유지하고 새 직업은 끝에 추가해 패시브 저장 순서를 보존한다.
Resources/CombatStats/<새 enum 이름>.asset을 만들면 공통 능력치 로더가 불러온다.
Resources/Careers의 baseJob·전직 조건·배율·외형 자산으로 분기를 추가한다.
별도의 직업 공격 방식과 연출은 그 직업 개발 시 구현한다. 지금은 미래 직업의 빈 구현을 만들지 않았다.
